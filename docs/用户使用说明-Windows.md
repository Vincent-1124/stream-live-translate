# Stream Live Translate 使用说明（Windows）

本说明适用于 Windows 版 OBS 和 `stream-live-translate-obs-win-x64-0.0.26.zip` 插件包。使用前请准备好自己的语音服务 API Key；服务商可能按用量收费。

## 第一步：安装

1. 先关闭 OBS，并解压插件包。
2. 打开解压后的 `stream-live-translate` 文件夹，双击 **`双击安装.cmd`**。
3. Windows 询问是否允许更改时选“是”。安装结束后会弹窗明确显示“安装成功”或“安装失败”；命令窗口也会保留详细信息，按任意键后才会关闭。
4. 重新打开 OBS。以后更新插件，也是先关闭 OBS，再运行同一个安装程序。安装程序不会删除已有的 Key、配置、录音和日志。

> 安装程序会使用 OBS 官方推荐的 Windows 公用插件目录
> `C:\ProgramData\obs-studio\plugins`，并同时兼容 OBS 32 和 OBS 33 的目录结构。

## 第二步：选择要出字幕的声音

在 OBS 的“来源”里，右键麦克风、媒体源等**有声音的来源**，选择“滤镜” → “+” → “实时字幕捕获”。只看得到画面、没有声音的来源，不会产生字幕。

## 第三步：填写 API Key

在电脑浏览器中打开：

```text
http://127.0.0.1:8787/admin
```

在“1. 大模型”里选择你使用的 API 服务，填入对应的模型名称和 API Key，点击“保存配置”，再点“测试已保存的连接”。看到音频和模型连接正常，就可以继续。请不要把自己的 Key 发给别人。

如果使用“百炼云 Fun-ASR”，可以在“2. 热词”里填写容易识别错的名称，每行一个，保存后查看“热词状态”。其它 API 服务不使用这项热词功能。

## 第四步：把字幕放到画面里

1. 在管理页“6. 实时字幕预览”下方，复制“OBS 字幕源 URL”中的**完整地址**。
2. 回到 OBS，在“来源”中点击“+” → “浏览器”，把地址粘贴到网址栏。
3. 宽度填 `1920`，高度填 `540`。确定后，把字幕源拖到画面中合适的位置，并放在其它画面来源的上方。
4. 对着刚才选择的音频来源说几句话，检查字幕是否出现。

请使用管理页给出的完整字幕地址，不要自己手写；也不要把这个地址发到公开场合。

## 想改字体或行数？

在管理页“5. 字幕样式”中修改，点击“保存配置”即可。设置“字幕最大行数”为 2，表示**最多显示两行**；短句只显示一行是正常的。

## 遇到问题时

- **找不到“实时字幕捕获”**：先完全退出 OBS，重新双击 `双击安装.cmd`，确认出现“安装成功”。再打开 OBS，查看“帮助 → 日志文件 → 查看当前日志”中是否有 `[SLT] Stream Live Translate plugin loaded`。
- **管理页打不开**：确认 OBS 已启动、插件已正确安装。
- **没有字幕**：确认滤镜加在有声音的来源上，再查看管理页是否提示模型连接失败；必要时重新填写 Key 并保存。
- **字幕没有出现在画面里**：确认 OBS 的“浏览器”来源填写的是管理页复制的完整地址，且该来源没有被隐藏。
